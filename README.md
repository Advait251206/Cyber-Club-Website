# Cyber Club Website

The official website for the **RBU Cyber Club** at Ramdeobaba University. A modern, interactive platform built to showcase club activities, team members, and events.

## 🚀 Tech Stack

- **Frontend**: React 19 (Vite), TypeScript, Tailwind CSS 4, Anime.js, React Router
- **Backend**: Node.js, Express 5, MongoDB (Mongoose)
- **Deployment**: Vercel (recommended configuration)

## 🛠️ Setup & Installation

### Prerequisites

- Node.js (v18+)
- MongoDB Atlas URI or local instance

## 🏗️ Structure

- `frontend/`: React application with Vite.
  - `src/components/`: Reusable UI components.
  - `src/pages/`: Main route views.
  - `src/data/`: Static data (e.g., Team Members).
- `backend/`: Express server API.
  - `models/`: Mongoose schemas.
  - `routes/`: API route handlers.
